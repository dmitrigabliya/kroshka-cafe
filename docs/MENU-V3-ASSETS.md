# Новые изображения меню · версия 3

Все девять изображений созданы встроенным `image_gen` в режиме built-in для вымышленной кофейни. Это иллюстрации концепта. Финальные JPEG находятся в `dist/assets/`; новые исходники PNG остаются в стандартной папке generated_images. Конвертация в JPEG выполнена для локальной доставки сайта.
