- Вторичный текст стал темнее для читаемости на бежевых поверхностях.
- Ошибка загрузки изображения больше не удаляет сам img и его id. Повторная успешная загрузка убирает сообщение об ошибке и возвращает изображение.

## Автоматические проверки и публикация

`python3 scripts/check_site.py` проверяет четыре HTML страницы, локальные файлы, внутренние якоря, alt текста изображений и фотографии каталога. `node --check` для обоих JS файлов пройден. Проверки запускаются и в GitHub Actions до публикации.

В репозиторий включается только папка этого проекта. Личные документы и аудио из родительской рабочей папки не включены. Проверка текстовых файлов на типовые форматы токенов и приватных ключей совпадений не нашла. В Pages загружается только dist.

Фактические загрузка и развёртывание требуют входа владельца в GitHub; до успешного ответа GitHub они не считаются выполненными. Проверка размеров выполнена в браузере, без физического телефона и отдельного прогона Firefox. Системная настройка reduced motion не переключалась.
