# Проверка локальной версии

Проверено 27 октября 2026 года в браузере приложения, без публикации на GitHub или другом хостинге.

## Пройдено

- JavaScript: `node --check dist/app.js`.
- HTML: проверены повторяющиеся ID, локальные файлы в href/src, якоря и alt фотографий. Все четыре страницы и их ресурсы доступны.
- `AGENTS.md` побайтно совпадает с установленным `landing-page-design/SKILL.md`; копия также включена в самостоятельную папку лендинга.
- Главная страница отдаёт HTTP 200. Неизвестный путь возвращает брендированную HTML-страницу 404; ссылка с неё возвращает на главную.
- В консоли браузера чистого первого экрана нет ошибок и предупреждений.
- Ширина 805 и 1280 px: первый экран и изображения просмотрены в обычных вкладках.
- Ширина 1440 px: страница просмотрена в локальном iframe соответствующей ширины. `scrollWidth = 1440`, горизонтального переполнения нет.
- Ширины 390 и 320 px: responsive-проверка в iframe, `scrollWidth` совпадает с шириной viewport. Заголовки и основной текст не выходят за экран. Исправлено обрезание первого заголовка на телефоне.
- Полноэкранное мобильное меню открывается. Переход из него в диалог брони работает.
- Категории меню переключают текст и фотографии. Стрелка вправо на клавиатуре переводит с кофе на завтраки.
- Пустое имя блокирует форму и показывает текстовую ошибку с фокусом на поле.
- Дата в прошлом блокирует форму и показывает текстовую ошибку.
- Прошедшие интервалы сегодняшнего дня недоступны в списке времени. Используется московское время.
- Демобронь с именем «Алексей», двумя гостями и общим столом показывает выбранные значения в подтверждении.
- Отмена переводит подтверждение в состояние «Демобронь отменена».
- Интерьер и манифест просмотрены при прокрутке; разделы появляются, текст манифеста раскрывается.
- Ответ FAQ раскрывается и показывает объяснение демоброни.
- Сохранены изображения первого экрана, атмосферы и подтверждения в `docs/`.

## Границы проверки

Проверка мобильных размеров выполнена в браузере, а не на физическом телефоне. Отдельные Safari/Firefox и экранный диктор не тестировались. Reduced motion реализован в CSS и JS, но системная настройка пользователя не менялась. Серверной части и настоящей записи в проекте нет по заданию. Публичный хостинг и GitHub Pages пока не проверялись, публикация отложена пользователем.

Локальный сервер запускался только для проверки. Для самостоятельного просмотра снова запустите `python3 serve.py` из папки проекта.
