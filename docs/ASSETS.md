# Материалы проекта «Крошка»

Все фотографии созданы для этого вымышленного концепта встроенным инструментом `image_gen` (режим built-in). Это не фотографии действующей кофейни. Финальные файлы лежат в `dist/assets/`, преобразованы из PNG в JPEG для загрузки в браузере. В интерфейсе нет сторонних запросов к фотостокам.

Шрифт: Manrope, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), локальные TTF 400/500/600/700. Лицензия SIL OFL включена в `dist/assets/Manrope-OFL.txt`.

Логотип набран Manrope. Солнце, favicon и простая линейная графика выполнены как SVG. Стрелки используют геометрию Phosphor. Никакие реальные отзывы или рейтинги не использованы.

Новый сгенерированный знак и его промпт: [LOGO-V2.md](LOGO-V2.md). Ниже сохранены исходные промпты фотографий; в них встречается название первого варианта «Тише».
